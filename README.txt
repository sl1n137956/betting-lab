Verdict — iPhone / website copy
===================================

This folder is a static website. Host all of these files together, then open
the site in Safari on an iPhone and tap Share → Add to Home Screen.

  index.html
  manifest.webmanifest
  sw.js
  apple-touch-icon.png
  icon-192.png
  icon-512.png
  icon-512-maskable.png
  favicon-32.png
  favicon-16.png
  favicon.ico

Needs a real https:// (or http://localhost) address. Opening index.html as a
file will not install as an app or turn on alerts.

Alerts only fire while the app is open. History and learning stay in that
phone's browser, separate from the desktop copy.
